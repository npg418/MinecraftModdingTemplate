# NPG418's Minecraft modding template
[Gradle](https://gradle.org/) + [Kotlin](https://kotlinlang.org/) Multi loader supported modding template.

This project uses composite build of [build-logic](./build-logic) project to share build logic.

## Usage
1. Replace `rootProject.name` in [settings.gradle.kts](./settings.gradle.kts) to individual project name
